# 用户管理页面发布

2026-10-19，功能提交 `4c9f13f` 已推送并部署。

- 正式页面：`https://linkaigo.com/workspace/admin/users`，管理员侧栏「用户管理」。
- 支持姓名/邮箱搜索、角色筛选、分页、注册时间、验证状态、投递次数与去重网站统计，以及带确认的管理员/普通用户权限调整。
- 后端按现有角色鉴权，限制自身权限修改，使用序列化事务与旧角色校验处理并发，不修改资料、经历或投递记录。统计口径、接口与审计说明见 [功能说明](../integration/admin-user-management.md)。
- 214 项相关测试、生产构建、4 组专用 PostgreSQL 集成检查和 Chrome 隔离全流程通过。Linux 候选镜像及静态资源检查通过。
- 正式站匿名用户 401，普通 QA 账号读取和权限修改均 403。正式站和隔离站健康检查正常，扩展仍为 0.3.9，其他容器保持不变。
- 发布前正式库管理员数为 0；用户明确指定账号后，仅将该现有、已验证账号设为首位管理员。正式服务读取校验通过，Chrome 使用该管理员会话成功展示用户管理列表。未提升其他正式账号。
